## 任务 3 能量机关识别与跟踪报告

### 1. 程序说明

本程序用于处理 RoboMaster 能量机关视频 `task_3.mp4`（小能量机关，最多 1 个目标同时点亮）、`task_4.mp4`（大能量机关，最多 2 个目标同时点亮）。

- 输入：视频文件
- 输出：`recognition_overlay.mp4`（可视化标注视频）、`binary_process.mp4`（二值掩码中间过程视频）
- 检测思路：HSV 红色阈值分割 → 形态学闭运算 → 轮廓层级分析，利用外轮廓子轮廓数量区分 R 标、扇叶。
  - `ringList`：圆度≥0.8 的外轮廓；`childCount≥2`判定为有效点亮扇叶
  - `rBlobList`：圆度不足、面积 180‑400，作为 R 标候选

### 2. R 标检测逻辑

1. 收集所有`childCount>=1`圆环圆心求算术平均得到集群中心`hub`；
2. R 标候选做面积过滤，圆环数量≥2 时开启 hub 距离限制；
3. **帧记忆策略**：上一帧 R 标有效，则优先选择距离上一帧 R 坐标最近的 blob，抑制单帧噪声跳变；
4. 连续`R_MAX_LOST=40`帧检测不到 R 标，则清空历史记忆，下次重新从 hub 搜索 R 标。

> 
> 参数：`R_BLOB_MIN_AREA=180`，`MAX_BLOB_TO_HUB=180`，连续丢失 40 帧清空 R 历史。

### 3. 扇叶目标跟踪逻辑

#### 3.1 匹配依据

以**R 标为中心**，计算每块有效扇叶相对于 R 标的角度；使用角度差做跨帧匹配。

- `ANGLE_THRESH=50`：角度差阈值，小于该阈值判定为同一个目标；
- `MAX_LOST_FRAME=30`：目标允许连续丢失最大帧数；超过则目标置为`inactive`；
- `MAX_R_LEAF_DIST=330`：扇叶轮廓中心距离 R 标最大允许像素距离。

#### 3.2 锁定规则（满足作业要求）

1. 首次出现有效目标：分配新`trackId`；
2. 当前目标处于 active 有效状态时，新出现的扇叶只会新增 track，**不会抢占已有 ID，保持原有目标身份**；
3. 短暂漏检：标记`LOST`状态，保留 trackId，在允许丢失帧数内等待重新匹配恢复；
4. 当目标连续丢失帧数超过`MAX_LOST_FRAME=30`，将目标置为`inactive`；后续再出现视为新目标，分配新 ID。

> 
> 注意：不会直接使用每帧轮廓数组下标作为 ID，依靠相对 R 标的角度特征做跨帧关联。

### 4. 可视化状态说明

- 绿色圆圈：有效`DETECTED`扇叶；黄色小圆点标记扇叶中心；红色连线：扇叶中心 ↔ R 标中心；
- 绿色十字：R 标中心；
- 画面左上角打印：`ID:xx DETECTED` / `ID:xx LOST`；
- R 标丢失时，R 标十字不再绘制，同时扇叶角度匹配逻辑关闭，不再做跟踪关联。

### 5. 参数表

表格

| 参数 | 数值 | 说明 |
| --- | --- | --- |
| HSV 红色低 | `(0,45,50)~(12,255,255)` | 红色色相第一段 |
| HSV 红色高 | `(168,45,50)~(179,255,255)` | 红色色相第二段 |
| 形态学闭核 | `Size(9,9)` | 闭合掩码断裂 |
| R 标最小面积 | 180 | 过滤极小噪声 blob |
| R 标 hub 最大距离 | 180 | 多圆环场景生效 |
| R 标连续丢失清空记忆 | 40 帧 | R 标长时间消失后重置 |
| 扇叶角度匹配阈值 | 50° | 跨帧匹配角度差上限 |
| 扇叶允许最大丢失帧 | 30 帧 | LOST 状态最大容忍时长 |
| 扇叶‑R 标最大距离 | 330 像素 | 过滤过远的扇叶轮廓 |

### 6. 已知问题与局限

1. 当掩码质量差，R 标轮廓断断续续，依然会出现 R 标短暂消失；可通过调小饱和度下限改善掩码；
2. 光照剧烈变化时 HSV 分割效果下降；
3. 若多个扇叶角度非常接近，可能出现匹配混淆；
4. 本任务不做角速度预测，仅做视觉检测 + 角度特征关联跟踪。
